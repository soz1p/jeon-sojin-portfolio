# Jeon Sojin · Graphics Portfolio

전소진의 그래픽스·물리 시뮬레이션 포트폴리오 웹사이트입니다.

## 파일 구성

- `index.html`: 페이지 내용, 스타일 및 상호작용
- `img/`: 프로젝트 이미지와 프로필 사진
- `files/`: 국·영문 CV 및 프로젝트 PDF

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다. `index.html`이나 자료 파일을 수정하고 커밋하면 사이트가 갱신됩니다. 배포 상태는 저장소의 Actions와 Settings → Pages에서 확인합니다.
